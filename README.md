# sided
Sided is a project meant to replace all the AI-slop with real human content.

# my vision
Me, like many others, grew tired of these AI videos overshadowing people's real work.

Sided is the project for this. We want to build an environment for people to grow and go viral without fearing that maybe AI will destroy their reach.

## Core principles 
- Human-only, no AI slop.
- Equality, so we don't treat users as metrics but actual people.
- Transparent moderation.
- No shadowbans. All content creators must know what they've done so they can stop repeating their mistake.

## Functionality
- A long-video format platform.
- Binging the creators you appreciate. Instead of the usual "Follow" or "Subscribe" crap I chose a name that works better.
- A Clean feed so people can find what they want fast.
- Modern tools for creators to manage their own community on the platform.
- Stories for bings. You, as the creator, can post short stories (5-60 minutes) to announce new videos or waiting for fast feedback. Only people binging you can see those stories.
- A 24-hour delay before posting so trolls or bots can't spread as fast.
- Badges for People posting (Green badge), for official music channels (Yellow), for official news outlets (Red) and for Individual journalists (Purple).
